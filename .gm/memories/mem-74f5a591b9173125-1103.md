NEVER use quickjs-emscripten 0.32 evalCode {type:'module', compileOnly:true}. QTS_Eval (c/interface.c) then calls JS_GetModuleNamespace on an uninitialized `module` pointer: bogus failures, leaked objects, and a JS_FreeRuntime list_empty abort that kills the shared WASM instance ('RuntimeError: unreachable' in the guest). Safe native module parse check (process.ts parsesAsModule): in a throwaway runtime evaluate `import "<file>"; import "owc:parse-check-stop";` with type module (not compileOnly). The loader returns the source for <file>, '' for other imports, and {error} for the stop module, so nothing links or runs. Only SyntaxError = parse failure. Module names must not contain NUL (truncated as a C string). esmSource order: regex gate, guest rxRewrite, parse check only if the rewrite changed something; keeps the 1.6 MB case within 5% of round 1. Hub: a host-owned unattached server side stays 'claimable' while the host holds the 'connection' payload (FinalizationRegistry, /// reference lib es2021.weakref), so late attach gets data>end>close like Node pauseOnConnect; heap flat at 100k.
