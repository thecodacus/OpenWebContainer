
## owc-shell-globbing (2026-10-16, commit 61c0d5b4f0)

Changed: packages/core/src/shell/commands/builtins.ts (quote-aware pathname expansion, component-by-component glob, `.` and `..` for a pattern beginning with a dot), packages/core/src/shell/commands/textutils.ts (a BRE/ERE `.` matches any character), packages/core/src/shell/shell.ts (`ls` prints a file operand's own name, `cat` concatenates every operand), packages/core/src/process/executors/node/runtime/capabilities/child.ts (`set -f` turns pathname expansion off, `ls` as above).

Differential witness, same command line under the host /bin/sh and in the container, stdout+stderr+exit compared: 20 lines x 2 shell paths = 40 comparisons, 0 differences. `echo *` -> a.txt b.txt c.md sub; `echo *.txt` -> a.txt b.txt; `echo ?.txt` -> a.txt b.txt; `echo [ac]*` -> a.txt c.md; `echo '*.txt'` -> *.txt; `echo "*.txt"` -> *.txt; `echo nomatch*` -> nomatch*; `grep . *.txt` -> a.txt:alpha / b.txt:beta; `find . -name "*.txt"` -> ./a.txt ./b.txt ./sub/e.txt; `ls *.txt` -> a.txt b.txt; `cat *.txt` -> alpha beta; `set -f; echo *.txt` -> *.txt; `.*` -> . .. .hidden; `su*/e.txt` -> sub/e.txt; `*/*.txt` -> sub/e.txt.

Playground witness (rebuilt packages/core/dist, vite --strictPort 5173, commands typed into the xterm terminal): the same eight cases give the same text as the host.
